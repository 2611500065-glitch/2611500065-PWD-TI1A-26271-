# P5 – JavaScript Dasar, DOM, Event, dan Validasi Sisi Klien

## Deskripsi

Pengembangan halaman web profil mahasiswa menggunakan HTML, CSS, dan JavaScript. Fitur yang dikembangkan meliputi navigasi responsif, manipulasi DOM, event listener, dan validasi formulir sisi klien.

## Fitur dan Pengembangan

1. **Navigasi responsif:** Tombol hamburger digunakan untuk membuka dan menutup menu navigasi pada layar kecil.
2. **Validasi formulir:** JavaScript memeriksa nama, email, dan program studi serta menampilkan pesan validasi.
3. **Interaksi formulir:** Pesan umpan balik ditampilkan setelah formulir dikirim dan dihapus ketika formulir di-reset atau input berubah.

## Pengujian

- **Navigasi hamburger:** Berhasil diuji pada tampilan seluler.
- **Formulir valid:** Menampilkan pesan bahwa formulir berhasil divalidasi.
- **Input tidak valid:** Menampilkan pesan kesalahan jika data tidak memenuhi ketentuan.
- **Batas pesan:** Pesan wajib diisi dan maksimal 300 karakter.

## Riwayat Pengembangan

- Menghubungkan JavaScript eksternal ke HTML.
- Memperbaiki ID menu navigasi agar tombol hamburger berfungsi.
- Menambahkan validasi formulir dan pesan umpan balik.
- Memperbarui tampilan CSS dan menguji halaman melalui Google Chrome.

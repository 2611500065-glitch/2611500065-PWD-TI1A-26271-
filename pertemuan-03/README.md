# Pertemuan 3 - Formulir HTML dan CSS Dasar

## Baseline
- Menggunakan hasil P2 sebagai dasar pengembangan P3.
- Menyalin `index.html` dan `img/foto-profil.jpg` ke `pertemuan-03/`.

## Implementasi Formulir
- Elemen form yang digunakan: `<form>`, `<label>`, `<input>`, `<textarea>`, `<select>`, dan `<button>`.
- Tipe input yang digunakan: text, email, password, number, date, dan radio.
- Atribut validasi yang digunakan: `required`, `minlength`, `maxlength`, `min`, `max`, dan `pattern`.

## Pengujian GET dan POST
- Hasil pengujian GET: Data formulir berhasil dikirim melalui URL dan dapat dilihat pada address bar browser.
- Contoh URL encoding yang ditemukan: spasi diubah menjadi `%20`, sedangkan karakter khusus seperti `@` dapat dikodekan menjadi `%40`.
- Hasil pengujian POST: Data formulir berhasil dikirim tanpa menampilkan data pada URL sehingga lebih aman untuk pengiriman data.

## CSS Dasar
- Selector elemen: `body`, `h2`, `h3`, dan `form`.
- Selector class: selector dengan tanda titik (`.`), misalnya `.form-group`.
- Selector ID: selector dengan tanda pagar (`#`), misalnya `#about`.
- Properti CSS dasar yang digunakan: `background-color`, `border`, `padding`, `margin`, `font-family`, `color`, dan `font-size`.

## Pengujian dan Perbaikan
- Galat yang ditemukan: Tampilan halaman awalnya belum memiliki styling CSS yang sesuai dan beberapa elemen belum tertata dengan baik.
- Penyebab galat: CSS belum diterapkan secara lengkap pada elemen HTML.
- Perbaikan yang dilakukan: Menambahkan dan memperbaiki selector serta properti CSS agar tampilan lebih rapi dan terstruktur.
- Hasil pengujian ulang: Halaman berhasil ditampilkan dengan baik, CSS diterapkan, dan elemen formulir dapat digunakan.

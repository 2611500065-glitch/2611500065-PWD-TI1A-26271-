

 **Konsep Dasar Pemrograman Web** adalah dasar untuk membuat dan mengembangkan website. Pemrograman web biasanya menggunakan **HTML** untuk membuat struktur halaman, **CSS** untuk mengatur tampilan, dan **JavaScript** untuk membuat halaman menjadi lebih interaktif. Selain itu, website dapat menggunakan server dan database untuk menyimpan serta mengolah data.



 **Konsep Dasar Pemrograman Web** adalah dasar untuk membuat dan mengembangkan website. Pemrograman web biasanya menggunakan **HTML** untuk membuat struktur halaman, **CSS** untuk mengatur tampilan, dan **JavaScript** untuk membuat halaman menjadi lebih interaktif. Selain itu, website dapat menggunakan server dan database untuk menyimpan serta mengolah data.<br>


 **Arsitektur Klien-Peladen** adalah sistem jaringan di mana klien meminta layanan atau data, sedangkan peladen (server) menyediakan dan memproses permintaan tersebut. Contohnya, saat membuka website, browser bertindak sebagai klien dan server mengirimkan halaman web yang diminta.<br>

 
 **HTTP Request dan Response** adalah proses komunikasi antara klien dan server melalui protokol HTTP.

HTTP Request: permintaan dari klien kepada server untuk mendapatkan atau mengirim data.
HTTP Response: balasan dari server yang berisi hasil dari permintaan tersebut.

Contoh: Browser meminta halaman website → server menerima request → server mengirim halaman sebagai response. <br>


**Pejelasan HTML,CSS,JAVASRIP,PHP,MYSQL**
HTML: Digunakan untuk membuat struktur dan isi halaman web.
CSS: Digunakan untuk mengatur tampilan dan desain halaman web.
JavaScript: Digunakan untuk membuat halaman web menjadi interaktif.
PHP: Bahasa pemrograman sisi server untuk mengolah data dan menjalankan fungsi pada website.
MySQL: Sistem basis data untuk menyimpan dan mengelola data website.

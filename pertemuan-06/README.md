# P6 — Pemrograman Web Dasar dengan PHP

## Deskripsi

Pengembangan halaman profil mahasiswa menggunakan HTML, CSS, JavaScript, dan PHP. PHP digunakan untuk menampilkan data profil secara dinamis melalui server lokal Laragon.

## Fitur dan Pengembangan

1. **Variabel dan konstanta:** Menyimpan data profil mahasiswa dan nama kampus.
2. **Tipe data:** Menggunakan string, integer, float, boolean, dan NULL.
3. **Operator dan kondisi:** Menggunakan operator, `if-elseif-else`, dan `switch`.
4. **Perulangan:** Menggunakan `for` untuk menampilkan target belajar dan `while` untuk menampilkan hobi.
5. **Fungsi PHP:** Menggunakan `htmlspecialchars()`, `number_format()`, `count()`, dan sintaks singkat `<?= ... ?>`.
6. **Integrasi halaman:** Mempertahankan CSS, JavaScript, navigasi, dan formulir dari P5.

## Cara Menjalankan

1. Pastikan folder `pertemuan-06` berada di dalam `C:\laragon\www\`.
2. Buka Laragon dan klik **Start All**.
3. Buka browser dan akses `http://localhost/pertemuan-06/`.
